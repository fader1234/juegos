# 🎮 Portal de Juegos

Colección de juegos para jugar en el navegador, sin instalar nada.

## Juegos

| Juego | Categoría |
|-------|-----------|
| Tres en raya | Estrategia |

## Cómo añadir un juego

1. Crea una carpeta `games/<id-del-juego>/` con su `index.html`.
2. Añade el juego a la lista en `js/games.js`.
3. Para el enlace de vuelta al portal, usa la barra `game-bar` (ver `games/tres-en-raya/`).

## Publicarlo

En GitHub: **Settings → Pages → Branch: `main` / `(root)` → Save**.
El portal quedará en `https://fader1234.github.io/juegos/`.
